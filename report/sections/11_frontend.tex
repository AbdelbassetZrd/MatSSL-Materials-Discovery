\section{Frontend Interface}

To demonstrate practical applicability, a web application, \textbf{MatSSL Studio}, was developed
with React (frontend) and FastAPI (backend). The backend exposes the deployed models through a REST
API (\texttt{/materials/predict}, \texttt{/analyze}, \texttt{/similar}, \texttt{/structure},
\texttt{/experiments}, \texttt{/models-info}). The frontend lets users build a chemical
composition, inspect its crystal structure, and receive stability, magnetism, metallicity and
photovoltaic band-gap predictions, each with an explanation and a reliability check. When the lowest-energy crystal structure of the composition is known (Alexandria),
the structure-aware high-accuracy models are used; otherwise the semi-supervised composition
models. Beyond
prediction, a \textbf{Research Lab} presents every experiment of this report interactively, a
\textbf{Compare} page ranks candidate materials side by side, and a guided \textbf{demo tour}
supports the oral presentation. The whole application ships as a single Docker image in which
FastAPI also serves the compiled interface.

The application has five sections:
\begin{itemize}
  \item \textbf{Overview:} project figures, the processing pipeline and the deployed models with
  their test scores.
  \item \textbf{Composition Studio:} an interactive periodic table (element cards, heat maps of
  electronegativity, radius or melting point), a formula box synchronized with the table, the
  atomic fractions and the lowest-energy crystal structure retrieved from the Alexandria
  database and rendered in 3D.
  \item \textbf{Results:} for every property, a probability gauge with the calibrated decision
  threshold, the selected method and its test metrics. The page also shows:
  \begin{itemize}
    \item a profile radar of the four probabilities;
    \item the position of the material in the training chemical space with the
    applicability-domain verdict;
    \item a ``why this prediction'' panel: exact SHAP contributions of the LightGBM-based models,
    or descriptor percentiles otherwise;
    \item the nearest known materials in the self-supervised embedding, with their true labels;
    \item the chemistry checks and the association rules that apply.
  \end{itemize}
  \item \textbf{Research Lab:} datasets and distribution shift, the SSL comparison with learning
  and label-budget curves, the selected models with ROC curves and confusion matrices, the
  genetic algorithm and applicability domain, the association-rule explorer and clusters, and
  the self-supervised autoencoder. It also works offline from a static copy of the results.
  \item \textbf{Compare:} up to four compositions side by side.
\end{itemize}
