# Materials Discovery with Semi-Supervised Learning (MI–SSL)

ESI-SBA – Machine Learning mini-project.

**Group members:** Laref Ibrahim · Nemouchi Faycal Abdelhadi · Zerradi Abdelbasset · Medelci Djezzar Aymen

Semi-supervised, unsupervised and self-supervised learning for predicting material
properties from the chemical composition, with large open materials databases:

| Task | Labeled data | Size (unique compositions) |
|---|---|---|
| Metallicity | Materials Project (Matbench `mp_is_metal`) | 77,432 |
| Magnetism | JARVIS-DFT 3D | 64,410 |
| Thermodynamic stability | Alexandria PBE 3D (5 chunks) | 436,791 |
| Photovoltaic band gap (GA + applicability domain) | Materials Project (Matbench `mp_gap`) | 78,164 |
| Unlabeled pool | GNoME (Google DeepMind) | 554,054 |
